# App Shelf — সেটআপ গাইড

আপনার অ্যাপ পোর্টফোলিও সাইট। ৩টি ধাপে Netlify-তে লাইভ করুন এবং লগিন-প্রোটেক্টেড এডমিন প্যানেল চালু করুন।

## ফোল্ডার স্ট্রাকচার
```
index.html          → মূল পেজ
css/style.css        → ডিজাইন
js/app.js             → apps.json লোড করে কার্ড রেন্ডার করে
data/apps.json        → আপনার অ্যাপের তালিকা (এডমিন প্যানেল থেকে এডিট হয়)
admin/                → লগিন-গেটেড এডমিন প্যানেল (Decap CMS)
images/uploads/        → স্ক্রিনশট এখানে জমা হবে
netlify.toml           → সিকিউরিটি হেডার
```

## ধাপ ১ — GitHub রিপোতে আপলোড করুন
Netlify-এর Identity + Git Gateway (লগিন সিস্টেম) কাজ করার জন্য সাইটটি অবশ্যই একটি Git রিপোজিটরি (GitHub/GitLab/Bitbucket) থেকে ডিপ্লয় করা লাগবে — শুধু ফাইল ড্র্যাগ-ড্রপ করলে এডমিন লগিন কাজ করবে না।

1. GitHub-এ একটি নতুন রিপো বানান (যেমন `app-shelf`)।
2. এই পুরো ফোল্ডারের ফাইলগুলো সেই রিপোতে পুশ করুন।

## ধাপ ২ — Netlify-তে ডিপ্লয় করুন
1. [app.netlify.com](https://app.netlify.com) → **Add new site → Import an existing project**
2. আপনার GitHub রিপো সিলেক্ট করুন। Build command খালি রাখুন, **Publish directory: `.`**
3. Deploy করুন — সাইট লাইভ হয়ে যাবে।

## ধাপ ৩ — Identity ও Git Gateway চালু করুন (এডমিন লগিনের জন্য)
1. Netlify সাইট ড্যাশবোর্ড → **Site configuration → Identity → Enable Identity**
2. Identity সেকশনে **Registration preferences → Invite only** সিলেক্ট করুন (যাতে অন্য কেউ সাইন আপ করতে না পারে — এটাই মূল সিকিউরিটি)।
3. **Services → Git Gateway → Enable Git Gateway**
4. **Identity → Invite users** থেকে নিজের ইমেইলে ইনভাইট পাঠান। ইমেইলে আসা লিংকে ক্লিক করে পাসওয়ার্ড সেট করুন — ব্যস, এখন আপনি একমাত্র এডমিন।

এখন `yoursite.netlify.app/admin/` এ গিয়ে লগিন করলে অ্যাপ যোগ/এডিট/ডিলিট করতে পারবেন, স্ক্রিনশট আপলোড করতে পারবেন — সব পরিবর্তন সরাসরি `data/apps.json` ফাইলে ও GitHub রিপোতে সেভ হবে, আর সাইট অটোমেটিক রিডিপ্লয় হবে।

## নিজের তথ্য দিয়ে কাস্টমাইজ করুন
- `index.html`-এ হিরো সেকশনের হেডলাইন/টেক্সট বদলে দিন।
- `data/apps.json`-এ শুরুর জন্য placeholder ডেটা আছে — এডমিন প্যানেল থেকে অথবা সরাসরি এই ফাইল এডিট করে বদলে ফেলুন।
- ব্র্যান্ড কালার বদলাতে চাইলে `css/style.css`-এর একদম উপরে `:root` এর ভেতরের `--accent` ও `--accent-2` ভ্যালু বদলান।

## বিক্রি/পেমেন্ট (bKash / Nagad / Rocket / Upay)
যেহেতু Merchant অ্যাকাউন্ট নেই, এখানে **ম্যানুয়াল Send Money + ভেরিফিকেশন** পদ্ধতি বসানো হয়েছে — অটোমেটিক পেমেন্ট গেটওয়ে নয়।

**সেটআপ:**
1. `admin/` প্যানেলে লগিন করুন → **Payment settings** → bKash/Nagad/Rocket/Upay-এর নিজের পার্সোনাল নাম্বার বসান।
2. যে অ্যাপ বিক্রি করতে চান, সেটার এন্ট্রিতে **"For sale?"** চালু করে দাম দিন — তখনই কার্ডে দাম ও "Buy now" বাটন দেখাবে।
3. Netlify ড্যাশবোর্ড → **Forms** → **Form notifications** থেকে নিজের ইমেইলে নোটিফিকেশন চালু করুন, যাতে কেউ অর্ডার করলেই সাথে সাথে জানতে পারেন।

**কীভাবে কাজ করে:** ক্রেতা "Buy now" চাপলে `checkout.html`-এ যাবে, পেমেন্ট মেথড বেছে bKash/Nagad/Rocket/Upay-এর *Send Money* অপশনে টাকা পাঠাবে, তারপর নাম/ফোন/ইমেইল/TrxID দিয়ে ফর্ম সাবমিট করবে। এই ফর্মটা Netlify Forms দিয়ে কালেক্ট হয় (কোনো ডাটাবেজ/সার্ভার লাগে না) — জমা পড়া অর্ডার আপনি Netlify ড্যাশবোর্ডের Forms সেকশনে দেখতে পাবেন।

**⚠️ গুরুত্বপূর্ণ:** এটা ম্যানুয়াল সিস্টেম — যে কেউ ফর্মে যেকোনো TrxID লিখে সাবমিট করতে পারে, তাই টাকা পাঠানো নিশ্চিত হওয়ার আগে **নিজের bKash/Nagad অ্যাপের স্টেটমেন্টে TrxID মিলিয়ে নিন**, তারপর অ্যাপ পাঠান।

**ভবিষ্যতে অটোমেটিক গেটওয়ে চাইলে:** bKash/Nagad-এর সাথে Merchant অ্যাকাউন্ট খুললে (ব্যবসা নিবন্ধন/ট্রেড লাইসেন্স লাগে) তাদের অফিসিয়াল Payment Gateway API যোগ করা যাবে Netlify Functions দিয়ে — তখন পেমেন্ট অটোমেটিক ভেরিফাই হবে, ম্যানুয়াল চেক লাগবে না। প্রয়োজনে তখন আবার বলবেন, আমি সেটাও বসিয়ে দেব।

## সিকিউরিটি নোট
- এডমিন প্যানেলে ঢোকার জন্য Netlify Identity-এর real লগিন লাগবে — ইনভাইট না করলে কেউ অ্যাকাউন্ট বানাতে পারবে না।
- `netlify.toml`-এ সিকিউরিটি হেডার (CSP, clickjacking প্রোটেকশন ইত্যাদি) যোগ করা আছে।
- PHP ব্যবহার করা হয়নি কারণ Netlify স্ট্যাটিক হোস্টিং — PHP রান করাতে পারে না। এই সেটআপে কোনো নিজস্ব সার্ভার/ডাটাবেজ ম্যানেজ করা লাগে না, তাই আক্রমণের সারফেসও অনেক কম।
